Voice MoMo

Mobile money à la voix — scannez, installez, testez. Android uniquement.

1. Télécharger

Télécharger l’application (Android) APK · démo Village 2026 · ~4 Mo

Si le bouton ne marche pas : ouvrir la page de release puis toucher app-debug.apk.

2. Installer (2–3 minutes)

  1. Autoriser les sources inconnues pour votre navigateur ou votre gestionnaire de fichiers (Paramètres → Applications → Accès spécial → Installer des apps inconnues).
  2. Ouvrir le fichier app-debug.apk téléchargé, puis toucher Installer.
  3. Au premier lancement, accepter : microphone, téléphone / appels, SMS (lecture des confirmations MTN), et activer le service Accessibilité Voice MoMo (nécessaire pour l’USSD).
  4. Saisir votre numéro MTN Bénin. Un code s’affiche à l’écran (démo) — saisissez-le pour entrer.
  5. Toucher le micro et dire par exemple : « Quel est mon solde » ou « Envoie 200 francs à … ».
À savoir avant de tester
  • Android uniquement — pas d’iPhone pour l’instant.
  • Pas encore sur le Play Store : l’avertissement « source inconnue » est normal.
  • Les transferts passent par l’USSD MTN sur votre SIM : c’est de l’argent réel. Préférez un petit montant.
  • Recharge / retrait / factures : l’app ouvre le menu USSD ; le parcours 100 % vocal n’est pas terminé pour ces cas.
